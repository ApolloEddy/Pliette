# Experiments · 动作候选与审阅记录

本目录保存 P1 阶段的 LLM 动作实验记录（Spec 2.2 / 2.3 / 6.5 / 15.1）。

## 约定

```
experiments/
  README.md                  本文件
  <日期>-<动作>-<轮次>/       每次实验一个目录
    prompt.md                输入包说明与提示词（能力表、绑定、数值域、动作目的）
    candidate-01.json        LLM 首次原始输出（保留，不覆盖）
    candidate-01-rev1.json   每轮修订（保留全部历史）
    diagnostics.json         校验/编译诊断
    review.md                Agent 初审评分与理由（0-5：协调/节奏/轮廓/风格；硬失败清单）
    media/                   录像与截图（大文件可放外部目录，此处只留索引；media/ 已 gitignore）
```

## 铁律

1. **保留第一次输出**：候选文件只增不改；人工修改单独标记，不计入 LLM 一次生成质量。
2. **六项对照动作**（Spec 2.3）：轻微待机、点头、单手小幅挥手、指向、倾身倾听、害羞收缩；每项保留原资源参考、首次生成、最多三轮反馈三种结果。
3. 不能把「从菜单选择已有动画」计入 LLM 创作验证；不能只交付合法 JSON 而不观察画面。
4. 进入正式 Preset 库的门槛：四项平均 ≥4 分、单项 ≥3 分、无硬失败（Spec 15.1）。
