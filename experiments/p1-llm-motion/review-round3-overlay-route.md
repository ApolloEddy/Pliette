# P1 路线转向：原动画切片叠加（专业数据复用）

日期：2026-09-08 凌晨 · 状态：**新路线验证成功，专业品质**

## 背景

用户否决了 Agent 手写关键帧动作（review-round1/2 的 candidate 系列）："单部位僵直、不达标"。经用户同意夜间探索新路线。

## 新路线核心思想

**不从零生成任何动作曲线，把拉菲自带的 20 段专业动画当作"动作素材库"来切片复用**：

1. **数据勘探**（scripts/mine-animations.mjs）：逐动画统计关键骨骼的运动幅度/范围/附件切换。发现：
   - `stand`（20.33s 待机）是宝库：face ±53°、手臂 ±160°、全套表情附件切换——待机本身就包含挥手/伸懒腰/左顾右盼等丰富表达
   - `touch`（0.67s）= 被摸头时眯眼开心的反应（eye_4 + meimao2）
   - `yun`（2s）含**螺旋晕眼**（eye_3）+ 摇晃
   - `normal`（4.67s）= 轻柔待机变体；`sit/sleep/walk/dance/tuozhuai` 各有 distinctive 姿态
2. **两轨道语义实证**：3.6.53 中高层轨道旋转在满权重时**绝对接管**该属性（非叠加），混合期平滑过渡、混出交还——即标准"手势接管"手感。
3. **切片叠加实现**（src/motion/library/overlay.ts）：按通道（head/face/leftArm/rightArm/torso）过滤源动画 timeline（排除 IK/绘制顺序/事件），`animationStart/End` 原生定义时间窗，窗口结束自动混出交还基础层。
4. **验证结果**：stand 打底 + touch:head 叠加 = 专业品质的"被摸头开心"反应；+ yun:head = **螺旋晕眼**表情叠加在自然待机上。表情全是美术资产，质量有保证。
