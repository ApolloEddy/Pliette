## 用户反馈与诊断

| 反馈 | 诊断 | 处置 |
| --- | --- | --- |
| 所有视频开头抖一下 | Lab 预览 bug：编译动画替换轨道 0 时与残留原动画做 0.2s 默认混合，前几帧处于混合态 | ✅ 已修：预览前瞬时清空轨道（mix=0），从 setup 无缝进入 |

| wave 只有胳膊动，其他部位僵直 | 真实实验数据点（Spec 2.1 预测的风险）：单部位动作不可接受，**必须 composite 协调** | ✅ 修订：wave 加头部偏向(6°)/躯干反倾(-3°)/起伏(0.008H)；point/shrink 同步协调化 |
| 视频糊 | 两者叠加：**主因是素材**——图集仅 1024×256（部件原尺寸小，放大近千像素必然软）；次因是录制 720p@crf20 | 录制端已提 crf18+30fps；素材分辨率是天花板，采集/渲染链路无损失引入 |
| 模型抖动 | 15fps 采样的时间混叠 + 开头混合 bug 叠加 | 30fps 重录 + 混合修复 |

## 对"项目方向"的判断（Spec 14 / P1 退出条件）

本轮实验已得到明确的负向数据点：**稀疏关键帧 + 单/少部位在 Q 版纸片角色上的首版质量不达标**（僵直、不可读）。但修订方向（composite 协调 + 可读幅度）在 c3/c2 峰值帧上已见效。按 Spec 14 P1 退出条款：若多轮后仍不达标，**回退路径是复用拉菲自带 20 段优质原动画做动作库主体，参数系统只做有界调制**（表情/幅度/节奏），项目不因此终止——这本来就是 Spec 预留的路线。判断点：本修订轮视频由用户复看后决定。
